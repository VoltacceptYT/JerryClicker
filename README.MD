# Jerry Clicker

A clicker game starring Jerry, available on multiple platforms. Each version lives on its own branch.

## Table of Contents

| Branch | Platform | Description |
|---|---|---|
| [`web-port`](https://github.com/VoltacceptYT/JerryClicker/tree/web-port) | Web Browsers | The original JerryClicker for web browsers |
| [`nds-port`](https://github.com/VoltacceptYT/JerryClicker/tree/nds-port) | Nintendo DS | JerryClicker for the NDS, ported from the original |

## Versions

### Web Browsers (`web-port`)

The original Jerry Clicker, playable in any web browser.

See the [`web-port` README](https://github.com/VoltacceptYT/JerryClicker/tree/web-port#readme) for details.

### Nintendo DS (`nds-port`)

A port of the original Jerry Clicker to the Nintendo DS using devkitARM + libnds. It uses the original sprites, font and UI, plus the original music converted to the DS's native IMA-ADPCM format.

- Touch and button controls, upgrades, prestige, golden Jerry bonuses
- Saves to `JerryClicker.sav` on a flashcart/SD (needs DLDI/FAT)
- Built automatically with GitHub Actions into `JerryClicker.nds`

See the [`nds-port` README](https://github.com/VoltacceptYT/JerryClicker/tree/nds-port#readme) for controls, build instructions and tested devices.
